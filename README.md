# Exposés M1 : IA en catalyse, chimie macromoléculaire et matériaux

25 sujets d'exposés d'actualité (15 minutes, binôme ou trinôme) pour le Master 1, avec un tableau d'affectation des groupes.

- `index.html` : page en ligne (filtre par domaine, ligne verte une fois le sujet affecté, export vers Excel). Les affectations saisies restent dans le navigateur de chaque visiteur.
- `Affectation_exposes_M1_IA_chimie.xlsx` : même tableau au format Excel, avec mise en couleur automatique.
